# 🛍️ Pixel Store

Mini e-commerce interativo de tecnologia e jogos, desenvolvido com HTML, CSS e JavaScript.

## 📌 Sobre o projeto

O Pixel Store é um projeto desenvolvido durante minha formação em Front-end no Senac, com o objetivo de praticar a construção de páginas web, estilização com CSS e interações utilizando JavaScript.

O projeto simula uma loja de produtos voltados para tecnologia e gamers, com navegação entre páginas, catálogo de produtos, cálculo de compras e formulário de atendimento.

## 🚀 Funcionalidades

- Navegação entre as páginas Início, Catálogo e Atendimento
- Apresentação de produtos em cards
- Saudação personalizada ao usuário
- Modo promoção com alteração visual da página
- Simulação de compra
- Cálculo do valor total da compra
- Desconto de 10% para compras com 3 unidades ou mais
- Verificação de frete grátis para compras a partir de R$ 500
- Formulário de atendimento
- Validação do nome do cliente
- Resposta personalizada de acordo com a idade
- Alterações visuais utilizando JavaScript

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Flexbox
